# Block types

The typical shape of each block, as a starting point for the analysis. The page in front of you wins over this table: describe what is there, not what is usual.

| Type | Job for the reader | Typical structure | Typical volume |
|---|---|---|---|
| `hero` | understand in five seconds what this is, for whom, and what to do | eyebrow? → h1 → subheadline → button (+ secondary link) → risk remover? | h1 4–10 words; subheadline 1–2 sentences, 15–30 words |
| `social_proof_logos` | see that others like them already use it | one line → row of logos or a customer count | line 5–12 words |
| `problem` | recognise their own situation | h2 → 2–4 pains (list or short paragraphs) | pains 8–20 words each |
| `solution` | see how the product removes the pain | h2 → 1 paragraph → optional illustration caption | 30–60 words |
| `features` | know what the product does | h2 → N × (h3 + p) | cards 10–25 words |
| `benefits` | know what changes for them | h2 → N × (outcome headline + one-sentence explanation) | headlines 3–6 words |
| `how_it_works` | believe it is easy to start | h2 → 3–4 numbered steps (verb + result) | steps 6–15 words |
| `use_cases` | find their own case | h2 → N × (role or scenario + what it does for them) | 15–30 words per case |
| `testimonials` | trust people like them | h2? → N × (quote + name + role + company) | quotes 15–40 words |
| `case_study` | see a result proved with numbers | h2 → situation → what was done → result in numbers | 60–150 words |
| `stats` | feel scale or proof at a glance | N × (number + 2–5 word label) | labels 2–5 words |
| `comparison` | see why this beats the alternative | h2 → table or two columns, "them vs us" | rows 3–8 words |
| `pricing` | choose a plan and see it is fair | h2 → toggle? → N × (plan name + price + who it is for + features + button) → note | features 2–6 words each |
| `faq` | have the last objections answered | h2 → N × (question + answer) | answers 20–60 words |
| `guarantee` | feel safe to try | h2 or badge → 1–2 sentences on what is guaranteed and how | 15–40 words |
| `about` | know who is behind it | h2 → story or mission paragraph | 40–120 words |
| `team` | see real people | h2 → N × (name + role + one line) | lines 5–15 words |
| `cta` | act now | h2 → one line → button → risk remover | h2 4–10 words |
| `lead_form` | leave contact details | h2 → why to fill it → fields → button → privacy note | 10–30 words around the form |
| `newsletter` | subscribe | one line on what they get and how often → field → button | 8–20 words |
| `other` | give the reason | | |

## Formulas worth recognising

Write them in the prompt as steps, never as their acronym.

- **Problem → agitate → solve:** name the problem, show what it costs, then the way out.
- **Before → after → bridge:** life now, life with the result, the product as the bridge.
- **Feature → advantage → benefit:** what it is, why that is better, what the reader gains.
- **Attention → interest → desire → action:** hook, reason to keep reading, wanting it, the step to take.
- **Question → answer:** a heading the reader would ask, answered at once.
