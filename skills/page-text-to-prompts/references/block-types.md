# Block types

The table shows the usual shape of each block. Describe what the page has, not what is usual.

| Type | Job for the reader | Usual structure | Usual volume |
|---|---|---|---|
| `hero` | understand in 5 seconds what this is, for whom, and what to do | eyebrow? → h1 → subheadline → button (+ secondary link) → risk remover? | h1 4–10 words; subheadline 15–30 words |
| `social_proof_logos` | see that people like them use it | 1 line → logos or a customer count | line 5–12 words |
| `problem` | recognise their own situation | h2 → 2–4 pains | pains 8–20 words each |
| `solution` | see how the product removes the pain | h2 → 1 paragraph → caption? | 30–60 words |
| `features` | know what the product does | h2 → N × (h3 + p) | cards 10–25 words |
| `benefits` | know what changes for them | h2 → N × (outcome headline + 1 sentence) | headlines 3–6 words |
| `how_it_works` | believe it is easy to start | h2 → 3–4 numbered steps (verb + result) | steps 6–15 words |
| `use_cases` | find their own case | h2 → N × (role or scenario + what it gives) | 15–30 words per case |
| `testimonials` | trust people like them | h2? → N × (quote + name + role + company) | quotes 15–40 words |
| `case_study` | see a result proved with numbers | h2 → situation → action → result in numbers | 60–150 words |
| `stats` | see scale or proof at once | N × (number + label) | labels 2–5 words |
| `comparison` | see why this beats the alternative | h2 → table or 2 columns, "them vs us" | rows 3–8 words |
| `pricing` | choose a plan and see it is fair | h2 → toggle? → N × (plan + price + for whom + features + button) → note | features 2–6 words each |
| `faq` | get the last objections answered | h2 → N × (question + answer) | answers 20–60 words |
| `guarantee` | feel safe to try | h2 or badge → 1–2 sentences: what is guaranteed and how | 15–40 words |
| `about` | know who is behind it | h2 → story or mission paragraph | 40–120 words |
| `team` | see real people | h2 → N × (name + role + 1 line) | lines 5–15 words |
| `cta` | act now | h2 → 1 line → button → risk remover | h2 4–10 words |
| `lead_form` | leave contact details | h2 → why to fill it → fields → button → privacy note | 10–30 words around the form |
| `newsletter` | subscribe | 1 line: what they get and how often → field → button | 8–20 words |
| `other` | give the reason in `reason:` | | |

## Formulas

Write a formula in the techniques as steps. Do not write its acronym.

- **Problem → agitate → solve:** name the problem, show its cost, then the way out.
- **Before → after → bridge:** life now, life with the result, the product as the bridge.
- **Feature → advantage → benefit:** what it is, why it is better, what the reader gets.
- **Attention → interest → desire → action:** hook, reason to read on, desire, the step to take.
- **Question → answer:** a heading the reader asks, answered at once.
